## Verbatim (original)

## Verbatim (English)

> Report bugs and learnings via decision records, or via task-file logs and messages when the record tools themselves are broken.

## Rationale

The repair targets the decision tooling itself, so a self-referential requirement would create a deadlock unless a fallback path is pre-authorized.
